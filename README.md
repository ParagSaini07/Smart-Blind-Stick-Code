# Smart Blind Stick (Arduino Based)

## 📌 Overview
The **Smart Blind Stick** is an Arduino-based assistive device designed to help visually impaired individuals detect obstacles while walking.  
It uses an **Ultrasonic Sensor** to measure the distance of objects in front and alerts the user through a **buzzer / vibration output**, improving safety and navigation.

---

## 🎯 Objective
To build a low-cost and practical solution that supports visually impaired people by providing real-time obstacle detection and alerting.

---

## ⚙️ Components Used
- Arduino UNO / Nano  
- Ultrasonic Sensor (HC-SR04)  
- Buzzer / Vibration Motor  
- Jumper Wires  
- Breadboard (optional)  
- Power Supply (Battery / USB)

---

## 🔧 Working Principle
1. The ultrasonic sensor continuously measures the distance of obstacles ahead.
2. If an object is detected within a set threshold distance:
   - The buzzer/vibration motor activates.
3. The closer the obstacle, the stronger or faster the alert (optional enhancement).
